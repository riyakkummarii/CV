The GitHub Pages portfolio sends its Gallery link to the Vercel deployment because the gallery API requires server-side environment variables. Configure the Vercel project with the values in `.env.example` before deploying the gallery.

## The idea behind it

A portfolio should do more than list job titles. This one is designed like a small product: clear on a phone, easy to explore, and full of the things I enjoy working on, from Playwright frameworks and AI testing to the projects and moments beyond QA.

- **Made with:** HTML, CSS, and JavaScript
- **The main theme:** building better tests, better feedback, and more confident releases
- **The gallery:** Cloudinary images served through a Vercel API route
